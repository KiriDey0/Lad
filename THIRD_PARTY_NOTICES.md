# Сторонние компоненты

`AGPL-3.0-only` относится к собственному коду Лада. Следующие компоненты сохраняют лицензии своих авторов; их уведомления нельзя заменять лицензией проекта.

| Компонент | Лицензия / уведомления |
| --- | --- |
| Golos Text | SIL Open Font License 1.1; файлы `Golos-Text-OFL.txt` в Android/TV и лицензия шрифта в desktop `licenses/` |
| Lucide | ISC; `Lucide-ISC.txt` в TV и уведомления desktop-зависимостей |
| yandex-music | LGPL-3.0, см. поставляемую копию лицензии в desktop `licenses/python/` и заголовки vendored-кода |
| JmDNS | Apache-2.0; `apps/tv/JmDNS-LICENSE.txt`, `JmDNS-NOTICE.txt` |
| SLF4J | MIT; `apps/tv/SLF4J-LICENSE.txt` |
| Gradle Wrapper | Apache-2.0; исходные уведомления в wrapper-скриптах |
| Electron, React, Kotlin, AndroidX, Media3, OkHttp, Coil, Haze и инструменты сборки | Лицензии соответствующих upstream-проектов и desktop-каталогов `licenses/`; версии зафиксированы в lockfiles и Gradle |

Исходники `backend/vendor/yandex_music` сохранены с исходными заголовками. Полный список desktop-уведомлений находится в `apps/macos/licenses/` и `apps/windows/licenses/`. Каталоги включаются в desktop-сборки. Торговые марки, обложки и музыкальный каталог не передаются под лицензией кода Лада.
