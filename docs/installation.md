# Установка и первый запуск

[← К проекту](../README.md)

## macOS

1. Скачай macOS ZIP из [последнего релиза](https://github.com/KiriDey0/Lad/releases/latest).
2. Распакуй архив и перемести `Лад.app` в «Программы».
3. Закрой предыдущий экземпляр приложения перед запуском новой версии.

Сборка предназначена для Apple Silicon и macOS 13+. Публичная сборка пока не имеет Developer ID / notarization: macOS может запросить разрешение на открытие в системных настройках безопасности. Проверяй источник скачивания и `SHA256SUMS`.

## Windows

Запусти `Lad-Windows-Setup-…-x64.exe` для установки текущему пользователю либо распакуй portable ZIP в отдельную папку и открой `Lad.exe`. Для обновления portable-версии закрой Лад и замени папку приложения. Пользовательские данные хранятся отдельно.

Приложение доступно через системный трей. Закрытие окна во время работы плеера скрывает его; команда «Выйти из Лада» завершает процесс. Сборка x64 предназначена для Windows 10/11 и пока не подписана сертификатом издателя.

## Android

Скачай телефонный APK, разреши установку для выбранного источника и установи пакет. Телефонная и TV-версии — разные приложения. Стекло с настоящим blur используется на Android 12+; на более ранних версиях применяется непрозрачный материал.

Текущие APK сохраняют сертификат первоначальных сборок проекта. Приватный ключ для выпуска хранится отдельно от исходников. Обновление поверх старой установки возможно только с той же подписью. Самостоятельно собранная APK с другим ключом не обновит установленное приложение; не удаляй старую версию, если хочешь сохранить её локальную сессию.

## Android TV / YaOS

Используй отдельную TV APK для Android 9+ / ARMv7. Перенеси её на телевизор подходящим файловым менеджером или установи через уже настроенный ADB:

```sh
adb -s <serial-телевизора> install -r Lad-TV-0.4.0-armv7.apk
```

Лад появляется в списке приложений и Leanback-лаунчере. Пульт с направлениями, OK и «Назад» достаточен для управления.

## Вход

На компьютере можно открыть окно Яндекса или войти по коду устройства. На Android и ТВ код подтверждается на официальной странице Яндекса с другого устройства. Пароль в интерфейсе Лада не вводится. Для просмотра интерфейса без аккаунта доступен режим знакомства с демонстрационными данными и без звука.

## Яндекс Станция

1. Подключи устройство с Ладом и Станцию к одной локальной сети.
2. Войди в аккаунт, которому доступна колонка.
3. Открой выбор устройства, обнови список и выбери Станцию.
4. Запусти музыку или передай уже играющий трек.

Если локальный поиск недоступен, введи адрес именно своей Станции вручную. Гостевая изоляция Wi-Fi и VPN могут мешать поиску устройств. Сторонний сервер, Bluetooth и постоянно включённый компьютер для телефонной/TV-версии не нужны.

## Контроль скачанного файла

SHA-256 указан в `SHA256SUMS` релиза. На macOS/Linux: `shasum -a 256 <файл>`. В PowerShell: `Get-FileHash <файл> -Algorithm SHA256`.
