# Orbit на Android и Windows

Orbit включается при первом запуске. Переключатель «Вернуться к старому дизайну» в конце настроек сохраняет выбор. Windows перезапускает процесс Лада через штатное завершение. Android пересоздаёт экран приложения, а движок воспроизведения остаётся в работе. Оба режима используют тот же профиль и ту же библиотеку.

Windows переносит интерфейс из проверенной macOS-сборки Orbit. В старом режиме загружается классический интерфейс Windows. Оба используют общий музыкальный сервис, системные кнопки окна, трей и существующую систему обновлений.

На Android приложение остаётся нативным. В Orbit используются раздельные капсулы мини-плеера и навигации, цвет обложки в мини-плеере, прогресс на подложке, свайп соседних треков с доводкой, персональные релизы, страницы исполнителей и раздел дизлайков. В превью релизов максимум шесть карточек. Полная подборка за 90 дней открывается по заголовку. При возврате из карточки сохраняется позиция просмотра.

## Проверка

- Android. Из `apps/android` выполнить `./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug`. Debug APK устанавливается отдельно как `com.lad.music.qa`.
- Windows. Из `apps/windows` выполнить `npm ci`, `npm run build`, `python -m pytest tests -q` и `npm run pack:windows` на Windows x64. Для проверок готовой сборки задать `LAD_TEST_EXE` и запустить `npx playwright test -c playwright.windows.config.ts`. Общие проверки совместимости запускают Classic, а системные проверки окна и стекла запускают Orbit.
- Для ручной проверки переключения открыть настройки с чистым тестовым профилем, включить Classic и перезапустить приложение. Выключить Classic и проверить возврат к Orbit. Сравнить сохранённые настройки и библиотеку в обоих режимах.

## Подготовка к слиянию

Ветка `codex/orbit-android-windows` основана на `origin/main`. Для ревью сравнить ветки через `git diff origin/main...HEAD`. Команда `git merge-tree --write-tree origin/main HEAD` проверяет результат объединения без смены ветки или создания коммита. Слияние и публикацию выполнить по отдельной команде.
