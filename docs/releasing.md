# Подготовка релиза

Начиная с 0.3.0 общий тег и приложения имеют единую версию из `release-config.json`. Примени её через `scripts/sync-version.py`. Android versionCode должен расти. Не меняй номер внутри готовой бинарной сборки без пересборки.

1. Обнови `CHANGELOG.md` и платформенные версии для затронутых приложений.
2. Дождись успешного CI. Собери desktop-пакеты на целевых ОС и Android/TV APK с сохранёнными ключами подписи через `scripts/build-native.py`. Нативные release-сборки выполняются начисто; не переиспользуй сгенерированные классы предыдущего номера.
3. Проверь установку/обновление и относящиеся к изменению ручные сценарии. В тестах используй отдельные QA-профили.
4. Запусти `python3 scripts/check-publication.py`. Проверь также содержимое бинарных архивов: они не должны содержать сессий, логов, приватных ключей, домашних адресов или пользовательских снимков.
5. Сформируй архив исходников из тега через `git archive`, SHA-256 для файлов и, при необходимости, общий ZIP. Добавь LICENSE и уведомления сторонних компонентов.
6. Создай draft GitHub Release, загрузи файлы, проверь ссылки/хэши и только после этого опубликуй.

Не пересобирай публичную версию с другим Android-ключом и не заменяй опубликованные артефакты молча: подпись определяет возможность обновления. Ключи, пароли и userData не хранятся в git или release assets. Для store-distribution нужны отдельные signing/notarization credentials; текущие публичные APK используют подпись тестовых сборок проекта.

## Типовой состав

- macOS Apple Silicon ZIP с `.app`.
- Windows x64 installer и portable ZIP.
- Телефонная Android APK и отдельная ARMv7 TV APK.
- Исходники, `LICENSE.txt`, `SHA256SUMS`.
- Опциональный all-platforms ZIP с теми же проверенными файлами.

Готовые приложения не коммитятся в репозиторий. Изображения в README должны содержать только демонстрационные данные.

Подписание `updates.json`, устройство протокола и требования к сохранению ключей описаны в [обновлениях приложения](updates.md). Этот файл публикуется вместе с бинарными файлами каждого нового релиза.
