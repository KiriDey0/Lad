# Безопасность

Для уязвимостей используй **Security → Report a vulnerability** в этом репозитории. Не публикуй секреты и детали доступа в обычном issue.

Укажи платформу, версию Лада, шаги воспроизведения и ожидаемый риск. Прикладывай только обезличенные данные. Если в отчёт попала действующая сессия, сначала отзови её через настройки аккаунта сервиса.

Исправления безопасности выпускаются для актуального публичного релиза. Подтверждённого срока ответа и поддержки старых версий проект пока не устанавливает.
